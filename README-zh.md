## 🌟 什么是 Rattib？
**Rattib** 是一个全能的 **Life OS (生活操作系统)**。它将任务管理、健康追踪、私密日记和财务管理整合在一个 100% 完全离线的应用中。

## 🌍 原生多语言支持
Rattib 并非简单的“机器翻译”，而是为 **8 种语言** 提供了完美的排版和文化适配：
1. 🇨🇳 **中文 (简/繁体):** 专为中文用户设计的完美排版。
2. 🇺🇸 **英语:** 全球通用的流畅体验。
3. 🇸🇦 **阿拉伯语:** 原生的 RTL (从右到左) 设计。
4. 🇪🇸 **西班牙语:** 本地化体验极佳。
5. 🇫🇷 **法语:** 优雅精确的界面。
6. 🇷🇺 **俄语:** 完美适配西里尔字母。
7. 🇮🇳 **印地语:** 针对印度次大陆的全面支持。

## 🎯 为什么选择 Rattib？
1. **告别应用疲劳:** 将任务、吃药提醒、日记和记账合并。
2. **绝对隐私 (离线优先):** 您的健康和日记数据加密保存在手机本地。绝不上传云端。
3. **本地 AI 助手:** 无需联网即可在本地设备上运行的 AI，为您提供优先级建议。
